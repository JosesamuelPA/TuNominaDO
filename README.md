# TuNominaDO

**TuNominaDO**, es una aplicación pensada para el procesamiento ficticio de nominas utilizando diferentes
tecnicas de transferencias con un proposito educativo en el cual estare aplicando los conocimientos que
voy aprendiendo durante el curso de los dias para ir llevando a la practica los conocimientos teoricos aprendidos

## Objetivos
Esta sera la lista de los objetivos que tengo pensado alcanzar durante el desarrollo de este aplicativo:

- Creación de un sistema simulado de pagos de nominas mediante el uso de diferentes vias de transferencias
- Vias de transferencias a implementar: FTP, SFTP, API REST, SOAP API, Archivos planos (Archivo de texto, json, xml)
- Implementación de firmas (SHA/RSA)
- Carga de datos en una base de datos relacional
- Realizar una aplicación Front End que puedan conectarse al Back End para el consumo de estos servicios

> Este proyecto se encuentra en etapa de desarrollo

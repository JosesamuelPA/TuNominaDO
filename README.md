# TuNominaDO

**TuNominaDO**, es una aplicación pensada para el procesamiento ficticio de nóminas utilizando diferentes
técnicas de transferencias con un propósito educativo en el cual estaré aplicando los conocimientos que
voy aprendiendo durante el curso de los días para ir llevando a la práctica los conocimientos teóricos aprendidos

## Objetivos
Esta será la lista de los objetivos que tengo pensado alcanzar durante el desarrollo de este aplicativo:

- Creación de un sistema simulado de pagos de nóminas mediante el uso de diferentes vías de transferencias
- Vías de transferencias a implementar: FTP, SFTP, API REST, SOAP API, Archivos planos (Archivo de texto, json, xml)
- Implementación de firmas (SHA/RSA)
- Carga de datos en una base de datos relacional
- Realizar una aplicación Front End que puedan conectarse al Back End para el consumo de estos servicios


## Tecnologías

Algunas de las tecnologías que utilizare para el proyecto:

- C# con .NET 10
- SQL Server
- ASP.NET Core

Estaré actualizando esta lista a la medida que vaya implementando otras tecnologías
